# postcard-migration

Read [skills.md](skills.md) for the full agent working rules.

**Key rule — Jupyter notebooks (`notebooks/*.ipynb`): never edit directly.**
Provide complete per-cell code snippets for the user to paste and run
themselves. All other files (scripts, schema, docs, config) may be edited
directly with the normal tools. for first time creation of notebook, you can directly create and put content, but when asked for edit, give code snippets.
